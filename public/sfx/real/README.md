# Real sound effects (override the generated ones)

Put a recorded sound here and register it in `index.json` under the same name as the generated one, e.g.

    { "lap": "dog-lapping-water.mp3", "splash": "water-splash.wav", "door": "wooden-door-creak.mp3" }

Every film that uses `sfx/lap.wav` will then play `sfx/real/dog-lapping-water.mp3` instead.
Only use sounds whose licence allows use in monetised YouTube videos (keep the source link in `CREDITS.md`).
